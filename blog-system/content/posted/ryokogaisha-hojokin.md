## 旅行会社が使える補助金は3つの系統に分かれる

**旅行会社の補助金は、IT・AIの導入、販路開拓、自治体の観光振興の3系統から目的で選びます**。旅行会社だけを対象にした国の補助金を探すより、汎用の制度に自社の業務を当てはめるほうが早く見つかります。

関連する内容として[電子カルテ情報共有サービスの補助金はクリニック対象外？](/blog/it-hojokin-denkaru-kyoyu-clinic/)も公開しています。

<figure><img src="/images/ryokogaisha-hojokin/keito.png" alt="旅行会社が使える補助金の3系統: 国のIT・AIはデジタル化・AI導入補助金、国の販路開拓は小規模事業者持続化補助金、自治体の観光は旅行商品の造成・送客の助成" loading="lazy"><figcaption>旅行会社が使える補助金の3系統</figcaption></figure>

1つ目は、国の*デジタル化・AI導入補助金*です。予約管理・顧客管理・問い合わせ対応・会計などのソフトウェア導入が対象になります。

2つ目は、国の*小規模事業者持続化補助金*です。チラシや商談会など、新しい客層を開拓する取り組みに使います。

3つ目は、都道府県や市町村の観光の補助金です。地域の素材を使った旅行商品の造成や、地域への送客を支える制度が自治体ごとに用意されています。

<div class="definition-box"><span class="term">デジタル化・AI導入補助金とは</span>、2025年度までの「IT導入補助金」が2026年度に改称された国の補助金です。中小企業・小規模事業者がITツールやAIを導入する費用の一部を補助します。</div>

業種名と補助金を組み合わせた語は、検索で上位に出るまで読まれにくい傾向があります。**当サイトの実測では、「美容室 レジ 補助金」は平均12.3位で25回表示されました**（自社サイトのSearch Console・直近28日・2026年10月時点）。1ページ目に届くまでは、クリックがほとんど発生していません。

旅行会社向けの解説も同じ事情で、検索ですぐ見つかる記事だけでは制度を取りこぼします。だから本記事では、3系統すべてを1か所にまとめました。

## 旅行会社は小規模事業者？従業員5人が分かれ目

**旅行会社はサービス業に区分され、常時使用する従業員が5人以下なら小規模事業者に入ります**。持続化補助金を使えるかは、この5人の線で決まります。

近い論点を[中小企業庁の補助金6制度](/blog/chusho-kigyocho-hojokin/)で扱っています。

あわせて[宿泊業の補助金は3つの入口｜目的別の選び方と優先順位](/blog/shukuhakugyou-hojokin-erabikata/)もご覧ください。

中小企業者かどうかは、<a href="https://laws.e-gov.go.jp/law/338AC0000000154" target="_blank" rel="noopener">中小企業基本法</a>のサービス業の基準で判定します。資本金5,000万円以下か、従業員100人以下のどちらかを満たせば中小企業者です。

| 区分 | 資本金 | 常時使用する従業員 |
|:--|:--|:--|
| 中小企業者（サービス業・旅行業を含む） | 5,000万円以下 | 100人以下（どちらか一方） |
| 小規模事業者（商業・サービス業） | 基準なし | 5人以下 |
| 小規模事業者（宿泊業・娯楽業） | 基準なし | 20人以下 |

<a href="https://mirasapo-plus.go.jp/hint/28890/" target="_blank" rel="noopener">中小企業庁のミラサポplus</a>は、持続化補助金の小規模事業者を「商業・サービス業（宿泊業・娯楽業を除く。）は5人以下」と案内しています。旅行業は宿泊業ではないため、5人以下の基準が当てはまります。

**宿泊業の20人以下の基準を、旅行会社に当てはめることはできません**。ツアーで旅館と一緒に仕事をしていても、判定は自社の業種で行います。役員と個人事業主本人は、従業員の人数に数えません。

従業員が6人以上の旅行会社は、持続化補助金の対象から外れます。その場合は、デジタル化・AI導入補助金か自治体の制度が候補として残ります。

## 旅行会社の予約・問い合わせ業務で満たす申請要件

**デジタル化・AI導入補助金の通常枠は、補助率1/2・補助額5万〜450万円で、次の締切は2026年10月30日です**。旅行会社の予約管理や問い合わせ対応のソフトも、事務局に登録されたITツールなら対象です。

| 項目 | 通常枠の内容 |
|:--|:--|
| 補助額 | 5万〜150万円未満（業務プロセス1〜3）／150万〜450万円（4以上） |
| 補助率 | 1/2（最低賃金近傍の事業者は2/3） |
| 申請前に要るもの | GビズIDプライム、SECURITY ACTIONの一つ星か二つ星 |
| 計画の数字 | 労働生産性を1年後3%以上、年平均3%以上伸ばす3年計画 |
| 次の締切 | 6次締切 2026年10月30日17時（交付決定は12月10日予定） |

出典は<a href="https://it-shien.smrj.go.jp/pdf/it2026_koubo_tsujyo.pdf" target="_blank" rel="noopener">公募要領（通常枠）</a>と<a href="https://it-shien.smrj.go.jp/schedule/" target="_blank" rel="noopener">事務局のスケジュール</a>です。7次締切の日付は、10月19日時点でまだ公表されていません。

補助額が150万円以上になる計画では、賃上げの要件が加わります。給与支給総額を年平均3%以上増やし、事業場内最低賃金を地域別最低賃金より30円以上高くする計画です。

旅行会社の業務に置き換えると、対象になりうるのは次のようなソフトです。

- 電話・メールの問い合わせに答えるAIチャット
- 予約・顧客情報を一元管理するシステム
- 見積・請求書の作成と会計ソフト

## ツアー造成や送客は自治体の観光補助金で探す

**ツアーの企画や地域への送客にかかる費用は、国のIT補助金ではなく自治体の観光補助金で探します**。自治体の制度は年度ごと・地域ごとに内容が違うため、所在地と旅行先の両方の自治体を調べます。

例として、島根県の<a href="https://www.pref.shimane.lg.jp/tourism/tourist/kankou/josei/miryokuaru.html" target="_blank" rel="noopener">魅力ある観光地域づくり支援事業補助金</a>（令和8年度・二次募集）があります。「地域資源を活用した旅行商品の造成支援事業」は、補助率1/2・上限100万円です。

| 項目 | 内容（島根県の例） |
|:--|:--|
| 対象者 | DMO・観光協会・法人など（県内に本社か営業所があること） |
| 補助率・上限 | 1/2・100万円 |
| 締切 | 2026年12月10日（上限に達した時点で終了） |
| 実績報告 | 2027年3月5日必着 |

旅行会社が対象に入るかは、要件の「法人」「県内の営業所」に当てはまるかで決まります。<span class="txt-red">予算の上限に達すると、締切の前でも受付が終わります。</span>

探すときは、都道府県と市町村の観光課のページで「旅行商品 造成」「送客 助成」と検索してください。国の観光の補助事業は、事業ごとに申請者の条件が違います。単独で申請できるかは、各事業の公募要領で確かめます。

## 目的別に見る旅行会社の補助金の選び方

**選び方は「何にお金を使うか」で決まり、ソフトならAI導入補助金、集客なら持続化、ツアーなら自治体です**。1つの経費を2つの補助金で重ねて受け取ることはできません。

| やりたいこと | 合う制度 | 向かない使い方 |
|:--|:--|:--|
| 予約・問い合わせ・会計をソフトで省力化する | デジタル化・AI導入補助金 | 広告費や予約サイトの掲載料 |
| チラシや商談会で新しい客層を集める | 持続化補助金（従業員5人以下） | 従業員6人以上の会社 |
| 地域の素材でツアーを造る・送客する | 自治体の観光補助金 | 対象地域の外で完結する商品 |

従業員5人以下の旅行会社なら、IT化はAI導入補助金、集客は持続化補助金と分けて組み合わせられます。従業員が6人以上なら、AI導入補助金と自治体の制度の2本で考えます。

申請を待つべき場合もあります。**2026年に開業した個人事業主は、2026年度のデジタル化・AI導入補助金に申請できません**。確定申告書の控えなど、前年分の書類が求められるためです。

GビズIDプライムをまだ持っていない会社も、10月30日の締切は見送るのが現実的です。取得には日数がかかるので、7次締切以降を狙って準備を始めてください。

持続化補助金の第20回〈一般型・通常枠〉は、<a href="https://j-net21.smrj.go.jp/snavi2/articles/183798" target="_blank" rel="noopener">J-Net21</a>によると受付が11月5日〜12月15日17時です。商工会・商工会議所が発行する様式4の受付は、12月4日までです。補助率は2/3（条件を満たすと3/4）です。持続化補助金とほかの制度の使い分けは、[小規模事業者持続化補助金は中小企業も対象](/blog/jizokuka-hojokin-chusho-kigyo-taisho/)で詳しく比べています。

## 旅行会社が補助金でつまずく3つの失敗

**旅行会社の失敗は、契約の時期、小規模事業者の判定、経費の取り違えの3つに集中します**。どれも、申請の前に確かめれば防げます。

<figure><img src="/images/ryokogaisha-hojokin/shippai.png" alt="旅行会社のつまずきと避け方: NGは交付決定前にツールを契約することと宿泊業の20人基準で判定すること、OKは契約を交付決定の後にすることとサービス業の5人基準で判定すること" loading="lazy"><figcaption>旅行会社のつまずきと避け方</figcaption></figure>

### 失敗1: 繁忙期の前に急いでツールを契約する

起きることは、補助が1円も出ないことです。**交付決定の前に契約・発注した経費は、補助の対象になりません**。

原因は、旅行シーズン前に導入を間に合わせたいという焦りです。避けるには、見積の取得までにとどめ、契約は交付決定（6次締切分は12月10日予定）の後にします。

### 失敗2: 宿泊業の基準で小規模事業者だと思い込む

起きることは、要件の取り違えです。例えば従業員8人の旅行会社は、持続化補助金の要件を満たしません。原因は、旅館もホテルも旅行会社も「観光業」とひとくくりにすることです。

避けるには、常時使用する従業員を数え直します。旅行会社の線は5人以下で、宿泊業の20人以下ではありません。

### 失敗3: 集客の費用をAI導入補助金で出そうとする

起きることは、ツアーの広告費や予約サイトの掲載料を計画に入れ、対象外として外されることです。原因は、集客とIT化を同じ「デジタル化」と考えることです。

避けるには、集客は持続化補助金か自治体の制度、業務のソフト化はAI導入補助金と分けて計画します。申請全般の失敗例は、[AI導入補助金の申請に失敗する5つの原因と対策](/blog/ai-hojokin-shinsei-shippai-yokuaru/)でも整理しています。

申請の要件に自社が当てはまるかは、[3分の適性診断（無料・8問）](/#diagnosis)で確かめられます。登録は不要で、その場で点数が出ます。

**今月中にGビズIDプライムの取得とSECURITY ACTIONの宣言を済ませると、次の締切に間に合わせやすくなります**。この2つは、ツールが決まる前から進められます。

3. 登録支援事業者と相談し、導入するツールを決める
4. 公表された締切から逆算して、申請と契約の日程を組む
