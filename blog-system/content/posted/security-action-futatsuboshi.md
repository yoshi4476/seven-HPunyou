## SECURITY ACTIONとは何か

SECURITY ACTIONは、中小企業が情報セキュリティ対策への取り組みを自ら宣言する無料の制度です。国のお墨付きを取得する認定制度ではなく、あくまで自己宣言である点を押さえておく必要があります。

<div class="definition-box"><span class="term">SECURITY ACTIONとは</span>、IPA（独立行政法人情報処理推進機構）が実施する、中小企業自身が情報セキュリティ対策への取り組みを宣言する制度です。★一つ星と★★二つ星の2段階があり、宣言すると専用のロゴマークを自社のウェブサイトや名刺に使用できます。</div>

*情報セキュリティ*への取り組みは、規模の小さい企業ほど後回しにされがちなテーマです。私たちが補助金申請の相談を受ける中でも、==「セキュリティ対策と言われても何から手をつければいいか分からない」==という声を何度も聞いてきました。SECURITY ACTIONは、その最初の一歩を形にする仕組みとして設計されています。**IPAは「認定」ではなく「宣言」という言葉を使うよう案内しており**、取得や合格ではなく自主的な意思表示だと理解しておくと制度の位置づけを誤解しません。

## ★一つ星と★★二つ星の違い

一つ星は取り組む意思の宣言で、二つ星は自己診断と方針の公開まで済ませた宣言という点が最大の違いです。両者とも無料で、申請の難易度も大きくは変わりません。

一つ星は「中小企業の情報セキュリティ対策ガイドライン」が示す情報セキュリティ5か条に取り組むことを宣言するだけで足り、対策の実施前でも申し込めます。一方で二つ星は、5分でできる情報セキュリティ自社診断を実際に行い、その結果を踏まえて情報セキュリティ基本方針を策定し、外部へ公開することが条件です。<a href="https://www.ipa.go.jp/security/security-action/twostar/" target="_blank" rel="noopener">IPAの二つ星宣言ページ</a>では、この基本方針を「理念、指針、原則、目標等を表した方針書」と定義しており、自社ウェブサイトや会社案内など複数の公開方法から選べます。

| 項目 | ★一つ星 | ★★二つ星 |
|:--|:--|:--|
| 宣言の位置づけ | 取り組む意思の宣言 | 自己診断・方針公開まで済ませた宣言 |
| 必須の取り組み | 情報セキュリティ5か条への言及 | 5分でできる自己診断の実施 |
| 追加の必須要件 | なし | 情報セキュリティ基本方針の策定・外部公開 |
| 対策の実施前でも宣言可能か | 可能 | 診断・方針公開が前提のため不可 |
| 費用 | 無料 | 無料 |

**取引先や自治体から見た印象は、二つ星のほうが「実際に手を動かした企業」として伝わりやすい**という違いがあります。どちらも交付申請の要件を満たすため、優劣というより「どこまで実務に落とし込んだか」の違いだと捉えてください。

## ★★二つ星を宣言する4つのメリット

二つ星を選ぶ主なメリットは、社内体制の可視化・対外的な信頼・補助金以外の場面での活用・将来の認証取得への布石の4つです。単に星が1つ増えるという以上の実務的な意味があります。

1点目は、自社診断を通じて自社の弱点が数値として可視化されることです。25項目の診断を実際にこなすと、感覚では気づきにくい抜け漏れが見えてきます。後回しにしていたパスワード管理の甘さや、更新が止まったバックアップ体制。2点目は、情報セキュリティ基本方針を外部公開することで、取引先や採用候補者に対して==「対策を語るだけでなく実行している会社」==という印象を与えられる点です。

3点目は、**大企業や自治体との取引で求められる委託先のセキュリティ確認に対応しやすくなること**です。私も相談対応の中で、二つ星の宣言と方針書の公開が、取引審査の説明資料としてそのまま使えたという声を聞いたことがあります。4点目は、二つ星の取り組みがISMS（情報セキュリティマネジメントシステム）認証やプライバシーマークといった、より本格的な認証取得の土台になることです。<span class="txt-red">一つ星のまま止まっていると、この土台づくりの機会を逃してしまいます。</span>いずれの認証も一足飛びには取得できないため、二つ星の実務経験が下地として役立ちます。

## 二つ星宣言に必要な2つの準備

二つ星の宣言には、5分でできる情報セキュリティ自社診断の実施と、情報セキュリティ基本方針の策定・外部公開という2つの準備が欠かせません。どちらもIPAが無料のひな形を提供しています。

自社診断は、25個の設問に答えるだけで自社の対策状況を把握できる簡易ツールです。PDF形式で配布されており、パスワード管理・バックアップ・従業員教育など幅広い項目を確認できます。診断結果をそのまま放置せず、==足りない項目を洗い出して改善計画に落とし込む==ことが、二つ星の実質的な価値を高めるポイントです。

情報セキュリティ基本方針は、**IPAが提供するサンプル（Word文書）を土台にして**、自社の事業内容に合わせて文言を調整すれば作成できます。策定した方針は、自社ウェブサイトへの掲載、会社案内への記載、その他の方法のいずれかで外部に公開する必要があります。<a href="https://www.ipa.go.jp/security/security-action/twostar/" target="_blank" rel="noopener">IPAの案内</a>によれば、公開方法は3つの選択肢から選べるため、ウェブサイトを持たない事業者でも宣言を進められます。

## 二つ星宣言の手順5ステップ【2026年4月の新システム対応】

二つ星の宣言は、GビズID取得から申込フォーム入力までの5ステップで完了し、2026年4月の新システム導入により宣言済IDの発行が申込直後まで短縮されました。以前より格段にスピーディーに手続きできます。

<a href="https://www.ipa.go.jp/security/security-action/news/sa-notice-202602.html" target="_blank" rel="noopener">IPAが2026年4月1日に公開した案内</a>によると、SECURITY ACTIONの申込システムが刷新され、GビズID（プライムまたはメンバー）を使ったログイン方式に切り替わりました。旧システムでは宣言済IDの発行に概ね1週間、ロゴマークのダウンロードには2〜3週間を要していましたが、**新システムでは申込直後に宣言済IDとロゴマークの両方が発行されます。**

1. 取り組み目標を決める（★一つ星か★★二つ星かを選択する）
2. GビズIDを取得する（未取得の場合。プライムアカウントの発行には概ね2週間かかる）
3. SECURITY ACTION管理システムの申込フォームに事業者情報・取り組み内容を入力する
4. 二つ星の場合は自己診断結果と基本方針の公開状況を申告する
5. 発行された宣言済IDとロゴマークをマイページから確認・ダウンロードする

<a href="https://www.ipa.go.jp/security/security-action/entry/" target="_blank" rel="noopener">IPAの申込方法ページ</a>では、申込にはGビズIDアカウントが必須であることが明記されています。**GビズIDの取得には時間がかかるため、補助金の申請スケジュールとは切り離して早めに着手する**のが安全です。

## 二つ星宣言でよくある3つのつまずきと注意点

二つ星宣言でつまずきやすいのは、基本方針を作っただけで満足すること、GビズIDの取得を後回しにすること、旧システムの宣言済IDをそのまま使い続けようとすることの3つです。

<div class="caution-box"><span class="box-title">注意: 基本方針は「公開」まで済ませて初めて条件を満たす</span><br>基本方針を社内文書として作成しただけでは二つ星の要件を満たしません。自社ウェブサイトへの掲載など、外部に公開する手続きまで完了させてください。</div>

弊社が申請支援の相談を受けた事例でも、==基本方針の文書は作ったのに公開作業を忘れていて、宣言が完了していなかった==というケースがありました。文書作成と外部公開は別の作業だと意識しておくと、こうした抜け漏れを防げます。

もう1つの注意点が、宣言済IDの世代交代です。<a href="https://it-shien.smrj.go.jp/news/40041" target="_blank" rel="noopener">デジタル化・AI導入補助金2026事務局の案内</a>によると、**2026年3月末までに取得した旧システムの宣言済ID（「4」から始まるID）は、第2次公募回以降の交付申請には使用できません**。第2次公募回以降に申請する事業者は、新システムで宣言済IDを取り直す必要があります。古いIDのまま安心していると、交付申請の段階でつまずくため注意してください。

## AI導入補助金とSECURITY ACTIONの関係

デジタル化・AI導入補助金2026の交付申請では、GビズIDプライムの取得に加えて、SECURITY ACTIONの一つ星または二つ星のいずれかの宣言が必須要件です。二つ星でなければ申請できないわけではありません。

事務局の申請手続きフローでは、交付申請の要件として「GビズIDプライム」と「SECURITY ACTIONの宣言（一つ星または二つ星）」の2点が明記されており、どちらの星でも要件そのものは満たせます。**申請の可否だけを考えるなら一つ星で十分ですが、前述のとおり取引先への説明や将来の認証取得を見据えるなら二つ星を選ぶ理由があります。**申請要件と経営上のメリットは分けて考えると判断しやすくなります。

なお、GビズIDとSECURITY ACTIONの準備不足そのものが不採択・応募断念につながる典型的な失敗パターンです。申請書類の書き方や実績報告の期限管理まで含めた失敗の全体像は、[AI導入補助金の申請に失敗する5つの原因と対策](https://lp.7senses.co.jp/blog/ai-hojokin-shinsei-shippai-yokuaru/)で詳しく解説しています。

## 二つ星を選ぶべき企業・一つ星で十分な企業の見分け方

二つ星を選ぶべきなのは、自治体や大企業との取引でセキュリティ確認を求められる企業、将来ISMSやプライバシーマークを目指す企業です。一つ星で十分なのは、まず補助金の要件を満たすことが最優先の企業です。

以下の3つの問いに1つでも当てはまるなら、二つ星まで進める価値があります。

- 取引先の与信・委託先審査でセキュリティ対策の状況を聞かれたことがある
- 採用活動や自治体入札の場面で、対外的な信頼材料を増やしたい
- 将来的にISMS認証やプライバシーマークの取得を検討している

逆に、今回の補助金申請だけが目的で、社内のセキュリティ体制づくりに時間を割く余力がない場合は、==まず一つ星を宣言して交付申請を進め、落ち着いてから二つ星の自己診断に取り組む==という順番でも問題ありません。<span class="big">大切なのは星の数そのものより、宣言した内容と実態が一致していることです。</span>実態の伴わない二つ星宣言は、後から取引先に指摘された際に信頼を損ねる原因になります。

## まとめ: 二つ星は「実務に落とし込んだ」ことの証明

SECURITY ACTIONの二つ星は、自己診断の実施と基本方針の外部公開まで済ませた、一つ星より一段階踏み込んだ宣言です。AI導入補助金の交付申請自体はどちらの星でも要件を満たせますが、取引先からの信頼や将来の認証取得を見据えるなら二つ星を選ぶ価値があります。2026年4月の新システムでは宣言済IDの発行が申込直後まで短縮されたため、以前より着手のハードルは下がりました。

まずはGビズIDの取得状況を確認し、自社診断で自社の弱点を洗い出すところから始めてください。地道な準備の積み重ねこそ、取引先からの信頼獲得への近道。セキュリティ体制を整えた後は、補助金で導入したAIツールをどう事業成長につなげるかが次のテーマになります。集客の観点からAI活用の全体像を押さえたい場合は[AI集客の完全ガイド｜AIO・LLMO・SEO・MEOの全体像](https://ai.7senses.co.jp/ai-marketing/ai-shukyaku-guide/)、AI検索での引用を狙う基礎知識は[AIO対策とは？AI検索に引用される5つの手順](https://ai.7senses.co.jp/aio/aio-taisaku-guide/)を参考にしてください。
