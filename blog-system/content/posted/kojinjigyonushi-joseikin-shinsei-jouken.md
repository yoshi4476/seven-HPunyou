**個人事業主が助成金を申請できるかは、「家族以外で、雇用保険に入っている従業員がいるか」でほぼ決まります。**売上や開業年数より先に、この1点を確かめてください。厚生労働省の雇用関係助成金は、雇用保険の適用事業所であることを最初の条件にしています。

1人で営む事業や、同居の家族だけで回している事業は、この時点で対象から外れます。その場合は助成金ではなく、補助金を探すほうが早く結論が出ます。

## 個人事業主が助成金を申請できる条件は何か

**個人事業主も法人と同じ条件で申請でき、最初に問われるのは雇用保険の適用事業所かどうかです。**法人でないことを理由に外されることはありません。

<div class="definition-box"><span class="term">助成金とは</span>、雇用や賃金の改善に取り組んだ事業主に、国が費用の一部を支給する返済不要のお金です。主に厚生労働省が所管し、要件を満たせば受け取れます。</div>

共通要領は、支給の対象になる事業主を次のように定めています。個人事業主が確かめるのは4つです。

| 条件 | 個人事業主が確かめること |
|:--|:--|
| 雇用保険の適用事業所であること | 申請日と支給決定日の両方で、加入している従業員がいる |
| 労働保険料を滞納していないこと | 前年度より前の保険料に未納がない |
| 審査や調査に協力し、書類を整えていること | 出勤簿・賃金台帳・雇用契約書がそろっている |
| 書類を5年間保存すること | 支給決定の翌日から5年間、写しを残せる |

出典は<a href="https://www.mhlw.go.jp/content/11600000/001688318.pdf" target="_blank" rel="noopener">厚生労働省「雇用関係助成金支給要領 共通要領」</a>です。

![個人事業主が助成金を申請できる4つの条件](/images/kojinjigyonushi-joseikin-shinsei-jouken/jouken4.png)

このほか、過去1年に労働関係法令の違反で送検された事業主や、接待を伴う1号営業の事業主は外れます。ふつうの個人商店や士業の事務所が当たることは、ほとんどありません。

## 家族だけ・1人の個人事業主は対象になるのか

**1人だけ、または同居の家族だけで営む個人事業主は、雇用関係助成金の対象になりません。**事業主本人は雇われる側ではないため、雇用保険に入れないからです。

見落としやすいのは家族です。厚生労働省の労働局は、**事業主と同居している親族は、原則として雇用保険の被保険者にならない**と案内しています。妻や子に給与を払っていても、それだけでは条件を満たしません。

例外もあります。次の3つをすべて満たす同居の親族は、雇用保険に入れることがあります。

1. 業務で事業主の指揮命令に従っていることが明確である
2. 働き方が他の従業員と同じで、賃金もそれに応じて払われている
3. 事業主と利益を一にする立場（取締役など）にない

出典は<a href="https://jsite.mhlw.go.jp/fukuoka-roudoukyoku/content/contents/001418452.pdf" target="_blank" rel="noopener">福岡労働局「同居の親族」雇用実態証明書に関する提出書類のご案内</a>です。加入できるかは、事業所を管轄するハローワークが判断します。

<div class="caution-box"><span class="box-title">注意: 別居の家族は扱いが違う</span><br>同居していない親族は、ほかの従業員と同じ基準で判定されます。週20時間以上働き、31日以上続けて雇う見込みがあれば、雇用保険の対象です。</div>

雇用保険に入る従業員の基準は、<a href="https://jsite.mhlw.go.jp/osaka-roudoukyoku/hourei_seido_tetsuzuki/roudou_hoken/hourei_seido/kosin/keizoku/tanni.html" target="_blank" rel="noopener">大阪労働局「労働保険の適用単位と対象となる労働者の範囲」</a>で確かめられます。**週20時間以上・31日以上の雇用見込み**の2つです。

## 個人事業主の「中小企業」はどう判定されるか

**資本金のない個人事業主は、常時雇用する労働者の数だけで中小企業かどうかが決まります。**多くの雇用関係助成金は、中小企業のほうが支給額が大きく設定されています。

あわせて[飲食店の補助金はいくら？](/blog/inshokuten-hojokin-ikura/)もご覧ください。

共通要領は、資本金を持たない個人などは労働者数で判定すると明記しています。業種ごとの上限は次のとおりです。

| 主な事業 | 中小企業になる労働者数 |
|:--|:--|
| 小売業（飲食店を含む） | 50人以下 |
| サービス業 | 100人以下 |
| 卸売業 | 100人以下 |
| 製造業・建設業などその他 | 300人以下 |

ここでいう「常時雇用する労働者」は、2か月を超えて雇い、週の所定労働時間が正社員とおおむね同じ人です。個人事業主でこの人数を超えることは、まずありません。

雇用保険の加入がまだなら、助成金の前に手続きが要ります。従業員を1人でも雇った個人事業主は、労働保険への加入が必要です。流れは次の3段階です。

1. 労働基準監督署に「労働保険 保険関係成立届」を出す
2. ハローワークに「雇用保険適用事業所設置届」を出す
3. 雇う従業員ごとに「雇用保険被保険者資格取得届」を出す

従業員はいるのに、2つ目の届出が抜けている個人事業主は珍しくありません。当社が相談を受けたときも、最初にこの届出の有無を確かめます。届出を済ませてから、使う制度を選んでください。

注意したいのは、経済産業省系の補助金とは数え方が違う点です。*小規模事業者*の基準などは制度ごとに別なので、申請する制度の要領で確かめてください。

## 業務改善助成金を個人事業主が使う条件と申請期限

**業務改善助成金は、いちばん低い時給を上げ、設備投資をした個人事業主も使えます。**ただし、引き上げる対象は週20時間以上の雇用保険の加入者に限られます。

あわせて[美容室の助成金とは｜歩合給でも使える5制度と金額の目安](/blog/biyoushitsu-joseikin/)もご覧ください。

近い論点を[AI導入補助金のAI活用事例5選【2026年最新】](/blog/ai-donyu-hojokin-jirei/)で扱っています。

関連する内容として[AI導入補助金の不採択理由7つと再申請までにやるべき対策](/blog/ai-hojokin-futaitaku-riyu/)も公開しています。

令和8年度の案内が示す主な条件は3つです。

1. 中小企業・小規模事業者であること
2. 事業場でいちばん低い時給が、今年度の新しい地域別最低賃金より低いこと
3. 解雇や賃金の引き下げなど、交付しない理由に当たらないこと

上限額は、引き上げ額（50円・70円・90円の3コース）と人数で決まります。**30人未満の事業者の上限は40万〜450万円**です。助成率は、引き上げ前の時給が1,050円未満なら4/5、1,050円以上なら3/4です。出典は<a href="https://www.mhlw.go.jp/content/11200000/001693416.pdf" target="_blank" rel="noopener">厚生労働省「令和8年度業務改善助成金のご案内」</a>です。

申請期限は、新しい最低賃金が発効する前日か、11月30日の早いほうです。当社が厚生労働省の<a href="https://www.mhlw.go.jp/stf/seisakunitsuite/bunya/koyou_roudou/roudoukijun/minimumichiran/" target="_blank" rel="noopener">令和8年度地域別最低賃金全国一覧</a>の発効日から数えました。**2026年10月5日の時点で、まだ期限内なのは22府県です。**

| 申請期限 | 府県（期限の日） |
|:--|:--|
| 10月7日〜17日 | 山口（7日）・島根（9日）・広島（10日）・秋田（13日）・静岡（14日）・福島（15日）・茨城（17日） |
| 10月23日〜31日 | 宮崎（23日）・鹿児島（24日）・青森（28日）・高知（28日）・山形（29日）・山梨・徳島・愛媛・大分（31日） |
| 11月 | 長崎（1日）・佐賀（14日）・京都（15日）・岩手・熊本・沖縄（30日） |

東京・大阪・愛知など残る25都道府県は、すでに期限を過ぎています。<span class="txt-red">期限内でも、交付決定の前に買った設備は対象外です。</span>

## 従業員を正社員にするならキャリアアップ助成金の条件

**パートや契約社員を正社員にする個人事業主は、キャリアアップ助成金の正社員化コースを検討できます。**中小企業なら、有期雇用からの転換で1人40万円です。

あわせて[歯科医院の助成金の対象は？](/blog/shika-iin-joseikin-taisho/)もご覧ください。

重点支援対象者に当たる有期雇用の人なら、40万円を2期に分けて最大80万円になります。無期雇用からの転換は1人20万円（重点支援対象者は40万円）です。出典は<a href="https://www.mhlw.go.jp/content/11910500/001687990.pdf" target="_blank" rel="noopener">厚生労働省「キャリアアップ助成金（正社員化コース）のご案内」</a>（令和8年4月8日版）です。

受け取るための手順は、個人事業主でも法人と変わりません。

1. 転換する前日までに、キャリアアップ計画を労働局に出す
2. 正社員に転換する制度を、就業規則などに書いておく
3. 転換後6か月の賃金を、転換前6か月より3%以上増やす

個人事業主がつまずきやすいのは2つ目です。労働基準法で就業規則の作成が義務になるのは、常時10人以上を使う事業場です。10人未満の個人事業主は、規則そのものが無いことがあります。転換制度を書いた規則が無いまま正社員にすると、条件を満たしません。

正社員として認められるには、**賞与か退職金、そして昇給の制度が適用されていること**も要ります。給与だけ上げて「正社員」と呼んでも、助成金の上では正社員になりません。

## 条件を満たしても受け取れない個人事業主の失敗例

**個人事業主の申請は、従業員の数え方と手続きの順番で失敗することがほとんどです。**当社が個人事業主から相談を受けると、次の点を最初に確かめています。

| 起きたこと | 原因 | 避け方 |
|:--|:--|:--|
| 妻を従業員として数えて申請を考えた | 同居の親族は原則、雇用保険に入れない | 家族以外の加入者がいるかで判断する |
| 従業員はいるのに条件を満たさなかった | 雇用保険の適用事業所の届出をしていなかった | ハローワークで加入手続きを先に済ませる |
| 正社員にした後で計画を出した | 計画は転換の前日までに出す決まり | 転換日を決める前に計画を出す |
| 時給を上げた後で申請した | 業務改善助成金は交付決定の後に実施する | 申請と交付決定を待ってから上げる |
| 古い保険料が未納のままだった | 滞納があると支給されない | 申請前に労働保険の納付状況を確かめる |

![個人事業主の助成金申請のNG・OK](/images/kojinjigyonushi-joseikin-shinsei-jouken/ng-ok.png)

特に多いのは1つ目です。家族経営の個人事業主ほど「給与を払っているから従業員だ」と考えがちです。給与を払っていることと、雇用保険に入れることは別の話です。

もう1つ、申請しない判断も必要です。**助成金のためだけに時給を上げたり人を雇ったりするのは勧めません。**上げた時給も雇った人の給与も、翌年以降ずっと続くからです。

## 従業員がいない個人事業主はどの制度を選ぶか

**従業員がいないなら、雇用関係助成金ではなく、経済産業省系の補助金を先に検討してください。**補助金は、雇っている人がいなくても個人事業主が申請できます。

状況ごとの分かれ方は次のとおりです。

| 個人事業主の状況 | 先に検討する制度 |
|:--|:--|
| 雇用保険の加入者がいて、期限内に時給を上げる | 業務改善助成金 |
| パートや契約社員を正社員にする予定がある | キャリアアップ助成金（正社員化コース） |
| 1人、または同居の家族だけで営んでいる | デジタル化・AI導入補助金（旧IT導入補助金） |
| 販路を広げるチラシ・ウェブサイトに使いたい | 小規模事業者持続化補助金 |

デジタル化・AI導入補助金は、2026年度から「IT導入補助金」が改称された制度です。会計ソフトや予約システム、AIを使った業務ツールの導入に使えます。個人事業主の条件は[個人事業主のAI導入補助金｜開業1年未満は対象外？](/blog/kojin-jigyonushi-ai-hojokin/)にまとめました。

当サイトの実測では、「it導入補助金 個人事業主」は平均2.0位に表示されながら、38回の表示でクリックが発生しませんでした。出典は自社サイトのSearch Console実測（直近28日・2026年10月時点）です。「個人事業主も対象か」という答えだけなら、検索結果で済むと考えられます。

実際に迷うのは、その先の「自分の場合はどれを選ぶか」です。当社はAI導入補助金の登録支援事業者として、対象ツールの選定から申請書類の作成、採択後の実績報告まで一貫して支援しています。

給付金・補助金・助成金の違いから整理したい方は[個人事業主の給付金・補助金](/blog/kojinjigyonushi-kyufukin-shinsei/)を、持続化補助金の採択の傾向は[小規模事業者持続化補助金｜個人事業主の採択率と対策](/blog/jizokuka-hojokin-kojinjigyonushi-saitakuritsu/)をご覧ください。

今日できる一歩は、**従業員の雇用保険の加入状況を、手元の資格取得の通知で確かめること**です。加入者がいれば助成金、いなければ補助金へと、そこで道が分かれます。
